EMBERLINE — pilot the last ember of a dying star: gather sparks, spend your light to dash through shadow wisps, and survive the storm waves. A complete 2D arcade game with waves, combos, power-ups, synthesized sound, and a results screen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys (or hold the mouse), dash with Space or click, P pauses, M mutes, R restarts from the results screen.
